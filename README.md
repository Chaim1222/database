# השוואת ערכים - ויקיפדיה העברית מול המכלול

## הגדרה נדרשת לפני הרצה
1. להריץ את `schema.sql` בעורך ה-SQL של סופרבייס.
2. להוסיף ב-Secrets של הריפו בגיטהאב: `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `MECHALOL_API_URL`.
3. לוודא ב-`config.py` שכתובת ה-API של המכלול וכתובות הקטגוריות מדויקות (הוגדרו לפי ההנחות מהשיחה, כדאי לאמת מול השרת בפועל).

## הרצה
- הרצה ראשונית: `workflow_dispatch` על `initial_run.yml`. אם נעצר באמצע (מגבלת זמן), פשוט להריץ שוב - ההתקדמות נשמרת.
- עדכון שוטף: `weekly_update.yml`, רץ אוטומטית כל יום ראשון.

## הערה
כרגע העדכון השבועי סורק מחדש את כל הכותרות בשני הצדדים (upsert, לא הרס נתונים קיימים).
לשיפור עתידי: מעבר לשליפת הפרש בלבד (recentchanges/newpages) כדי לקצר את זמן הריצה השבועי.
