# העברות לטיוטה בדוח ההעברות

**מצב נכון ל-8.10.2026: PR 104 מוזג; טבלת היומן ותצוגת המועמדים אומתו בייצור בקריאה בלבד.**

דוח ההעברות משתמש בכותרת הנוכחית בטבלת ויקיפדיה. אם המזהה אינו במרחב הראשי, הוא משתמש בהעברה האחרונה לטיוטה. העברה נוספת גוברת על יעד קודם; מחיקה מאוחרת מבטלת את הממצא, ושחזור של אותו מזהה אחרי המחיקה מאפשר אותו שוב. יומן מחיקה ללא מזהה נבדק לפי כותרת הטיוטה. זהו מצב לפי הסנכרון האחרון, לא בדיקה חיה באתר.

הריצה הרגילה והשלמת ההיסטוריה כותבות את כל ההעברות ומחיקות/שחזורי הטיוטות ליומן נפרד, maintenance_wikipedia_events. ביומן נשמרים מרחב המקור ומרחב היעד; מפתח ייחודי לפי סוג, כותרת, יעד וזמן אירוע מונע כפילות בהרצה חוזרת. תצוגת המועמדים קוראת אירועים רק ממנו. המיגרציה מעתיקה אליו את ההעברות הראשיות הקיימות בלי לשנות את יומני הדלתא. wikipedia_renames, wikipedia_deletions ו-wikipedia_creations שומרים על הסינון המקורי למרחב הראשי, כולל אירוע מחיקה סינתטי כאשר דף יוצא ממנו. החלת השינויים על wikipedia_pages נותרת במרחב הראשי. מרחב 118 הוא מרחב הטיוטה בוויקיפדיה העברית; קוד האיסוף והדוח מניחים אתר זה. מסנני זהות הגרסה והשיוך הידני הקיימים נשארים בדוח.

## סדר החלה

1. לפני מיזוג הקוד, להחיל migrations/20261007182648_draft_move_report.sql (דורש את המיגרציה 20261006205515 שכבר הוחלה), ולוודא שהטבלה maintenance_wikipedia_events קיימת. הקוד החדש דורש אותה גם בריצה הלילית; מיזוג לפני החלת המיגרציה עלול להכשיל את הדלתא.
2. למזג את בקשת המיזוג.
3. להריץ רענון תחזוקה. בהפעלה הראשונה למלא move_history_since בתאריך שקודם להעברות שרוצים להשלים, למשל 2026-09-01T00:00:00Z. השלמה זו כותבת ליומן התחזוקה הנפרד בלבד, בלי שינוי מראה או watermark; הסנכרון הרגיל ממשיך אחריה.
4. לוודא שהעברות לטיוטה מופיעות, ושלדפים שחזרו או נמחקו אין יעד טיוטה מיושן.

מגבלה ידועה: שחזור מבטל מחיקה בדוח רק אם מזהה הדף בשחזור תואם למזהה שבהעברה. שחזור עם מזהה שונה אינו מחזיר את הממצא; נדרש אימות זהות נפרד כדי לקבוע אם מדובר באותו דף. אין התאמה לפי כותרת בלבד, כדי לא לשייך דף אחר שקיבל את אותו שם. אימות כזה עדיין אינו ממומש.

אפשר לבדוק את ההשלמה ללא כתיבה: python scripts/fetch_wikipedia_delta.py --move-history-only --since 2026-09-01T00:00:00Z --dry-run.

בדיקות: unittest discover -s scripts/tests; PGLITE_PACKAGE_JSON=/path/to/package.json node scripts/tests/test_draft_moves_sql.mjs. חבילת package.json חייבת לכלול @electric-sql/pglite.
